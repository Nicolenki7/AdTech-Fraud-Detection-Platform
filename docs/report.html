Cómo se calcula

El resumen agregado es lo único que el informe consume.

  1. Los datos son sintéticos: los genera src/python/generate_sample.py con seed=42, igual que el dashboard.
  2. El script agrega 500 alertas por país y por prioridad y versiona el resumen en data/sample/alertas_resumen.csv.
  3. Bloqueo = alertas con acción BLOCK_IP_IMMEDIATELY / alertas de ese grupo.
  4. El informe lee el CSV agregado, no vuelve a simular: así el HTML y el CSV no pueden divergir.

Qué no dice este informe

Lo que una muestra simulada no puede afirmar.

  • Datos sintéticos: sirven para mostrar el pipeline y el panel, no describen fraude real.
  • El reparto por país es uniforme por construcción, así que el volumen no dice nada del mercado.
  • Con 500 alertas y 8 países, cada tasa se mueve ~3 puntos por caso.
  • No hay serie temporal: las marcas de tiempo del dashboard son horas relativas, no fechas.
